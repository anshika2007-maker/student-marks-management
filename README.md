# Student Marks Management

## 📌 About the Project
Student Marks Management is a Python-based project that helps calculate and manage student marks.

## ✨ Features
- Enter student marks
- Calculate total marks
- Calculate percentage
- Calculate grade
- Display student result

## 🛠️ Technology Used
- Python

## ▶️ How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:

```bash
python main.py
